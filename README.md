## Новости из ВКонтакте

Источник: https://vk.ru/cybermol, ID 213657881. Официальный виджет стены сообщества добавлен в раздел `#news`; подключение настраивается в `site-config.js`, загрузка в `vk-feed.js`, оформление в `vk-feed.css`.

Фомин публикует запись в сообществе ВК. При открытии раздела сайт получает актуальную ленту у ВК. Копировать запись в файлы сайта не нужно. Токен и пароль ВК не используются.

Виджет загружается при приближении к разделу, поддерживает изменение ширины и повторную загрузку. При недоступности внешнего скрипта остаётся ссылка на сообщество. Собственные сообщения ВК, включая проверку посетителя, показываются внутри виджета. Прямой импорт в собственные карточки или отдельный архив новостей не реализован.
